# Consulta de histórico no painel

Cada lançamento ativo oferece um link Histórico. Também é possível abrir /historico.html e informar um ID de lançamento excluído. O painel usa o endpoint paginado GET /api/pj/lancamentos/{id}/historico e mostra apenas os campos alterados de cada evento. Exige token válido e não realiza gravações. O token não é colocado na URL nem persistido; apenas o ID aparece na URL. Não compartilhe capturas com informações financeiras. Os registros são gerados após a migração e não constituem trilha inviolável ou identificação de pessoas.
